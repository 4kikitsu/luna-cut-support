# Luna Cut — 更新履歴・サポート

画像をPC内で切り抜き、透過PNGで保存するWindows向けアプリです。
ここは更新履歴・既知の制限・不具合報告を管理するリポジトリです。
アプリのソースコードを公開するリポジトリではありません。

**無料ベータ版は現在、配布準備中です。**

配布予定のBOOTHショップ：[四季橘](https://4kiki2.booth.pm/)
商品公開後、このページにダウンロード先を掲載します。

- [更新履歴](CHANGELOG.md)
- [既知の制限](KNOWN-ISSUES.md)
- 不具合・要望：このリポジトリのIssuesタブ

## 不具合を報告する前に

既存のIssuesと既知の制限を確認し、同じ内容がなければ新しいIssueを作成してください。
アプリのバージョン、Windowsのバージョン、再現手順、使用モデルを記載してください。
画像の添付は任意です。GitHub Issuesは公開されるため、個人情報や公開できない作品は添付しないでください。
サポートへの回答時期や、すべての要望への対応は確約していません。

## アプリについて

標準モデルU2Netと軽量モデルU2NetPを同梱しています。正常な同梱版はオフラインで処理できます。
画像のアップロードやアプリのアカウント登録は不要です。
自動処理で欠けた部分は復元ブラシで戻せます。

利用条件・プライバシー説明・第三者ライセンスは、公開時に配布ZIPへ同梱する予定です。
AIによる開発支援を利用しています。
